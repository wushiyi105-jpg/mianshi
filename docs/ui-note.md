# UI 说明：面试

- **谁在什么时刻打开**：给已有目标岗位的求职者。
- **首屏任务句**：同一个追问，这次答得更好吗。
- **主操作**：按「贴 JD 和经历 → 计时答一轮 → 同维度复练」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：排练台；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：排练台。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给已有目标岗位的求职者：按 JD 和真实经历出题，用同一套维度复练，比较遗漏证据、结构和时长，收成口袋卡。
